🎵 Sistema Musical - Catálogo Front-end

Este repositório contém o desenvolvimento da interface (Front-end) de um Catálogo de Sistema Musical. O projeto foi desenvolvido como entrega prática da atividade de Front-end das aulas 11 a 14, sob orientação do professor André Luis Denani.

🎯 Sobre o Projeto

O objetivo do projeto é criar a estrutura visual e navegável de um sistema de catálogo, aplicando conceitos de marcação de texto, estilização, variáveis CSS e responsividade. O sistema permite simular o fluxo desde o login até o cadastro e listagem de artistas e músicas.

💻 Telas Desenvolvidas

O projeto é composto por 5 telas interativas e interligadas:

Login (login.html): Tela de entrada do sistema com validação visual de campos (tentativa de cadastro com campo vazio).

Menu Principal (index.html): Dashboard/Menu de navegação para as demais áreas do sistema.

Cadastro do Criador (cadastro_artista.html): Formulário para registrar novos artistas/bandas no catálogo.

Cadastro da Obra (cadastro_música.html): Formulário para registrar novas músicas associadas aos artistas.

Listagem (listagem_músicas.html): Exibição em catálogo das obras cadastradas.

🛠️ Tecnologias Utilizadas

HTML5: Estruturação semântica de todas as páginas.

CSS3 (estilos.css): Arquivo de estilo único para todo o projeto, utilizando a pseudo-classe :root para definição da paleta de cores global do tema.

📱 Responsividade

A interface foi construída para se adaptar a diferentes tamanhos de tela. Todo o layout e funcionamento dos menus estão otimizados tanto para Computador (Desktop) quanto para Dispositivos Móveis (Celular).

🚀 Como testar o projeto

Faça o clone deste repositório ou baixe os arquivos em .zip.

Extraia os arquivos (se baixou em .zip).

Dê um duplo clique no arquivo login.html para abri-lo no seu navegador padrão.

Navegue pelos links para testar o fluxo das telas e utilize a tecla F12 (Modo Desenvolvedor do navegador) para testar a versão mobile.
